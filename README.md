### 📂 Proyectos Destacados

#### 📧 EverMail - Cliente de Correo de Escritorio
*(Mar 2026 - Presente)*
Aplicación de escritorio nativa desarrollada con **JavaFX** que soporta protocolos **IMAP/SMTP** y autenticación **OAuth 2.0** para cuentas de Google y Microsoft.
* 🏗️ **Arquitectura en Capas Estricta:** Implementé el patrón `Controller → Facade → Service → Repository → DAO` para desacoplar eventos de la UI de la lógica de negocio.
* ⚡ **Procesamiento Asíncrono:** Uso de `JavaFX Task<T>` y el patrón Facade para sincronización de correos y descarga de adjuntos sin bloquear el hilo principal.
* 🔒 **Seguridad:** Persistencia local segura integrando **SQLite** para caché y llaveros nativos del sistema operativo (*OS-native keyrings*) para cifrar credenciales y cuerpos de correo en reposo.

#### 🧮 JavaFX Scientific Calculator

* 📐 **Lógica Avanzada:** Procesamiento de operaciones complejas manteniendo la precisión y el rendimiento en tiempo real.
