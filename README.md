## 📂 Proyectos destacados

### 📧 EverMail — Cliente de correo de escritorio

**Java | JavaFX | SQLite | Jakarta Mail | OAuth 2.0**  
📅 Mar 2026 – Presente

Aplicación de escritorio nativa para gestión de correo electrónico con soporte para protocolos **IMAP/SMTP** y autenticación **OAuth 2.0** para cuentas de Google y Microsoft.

- Diseñé una arquitectura estricta por capas:  
  **Controller → Facade → Service → Repository → DAO**, separando la lógica de negocio de la interfaz gráfica.
- Implementé procesamiento asíncrono en segundo plano usando **JavaFX Task<T>** y el patrón **Facade**, evitando bloqueos en la interfaz durante la sincronización de correos, envío SMTP y descarga de adjuntos.
- Integré persistencia local segura con **SQLite** para caché y almacenamiento cifrado de credenciales usando mecanismos nativos del sistema operativo.
- Desarrollé una interfaz gráfica responsiva orientada a productividad, validación de archivos adjuntos y manejo seguro de sesiones.
