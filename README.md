### 📂 Proyectos Destacados

#### 📧 [EverMail](https://github.com/JuanPablo72000/Proyecto_01_TopicosAProgramacion) | *Java, JavaFX, SQLite, Jakarta Mail, OAuth 2.0*
Cliente de correo electrónico de escritorio nativo con soporte para protocolos IMAP/SMTP y autenticación segura.
- ⚡ **Arquitectura por capas estricta** (`Controller → Facade → Service → Repository → DAO`) que desacopla la UI de la lógica de negocio, logrando cargas de bandeja en **< 3s** y apertura de correos en **< 5s**.
- 🔄 **Procesamiento asíncrono** con `JavaFX Task<T>` para sincronización y envío SMTP sin bloquear el hilo principal (login en < 2s, envío en < 3s).
- 🔒 **Seguridad y persistencia**: Caché local de los últimos 50 correos en SQLite, almacenamiento de credenciales con hashing/tokens bajo estándares **ISO/IEC 27001** y validación regex de destinatarios.

#### 🏦 [Adaptive Personal Banking](https://devpost.com/juanpablorodriguezhurtado) (Reto Banorte - HackMty) | *Tailwind CSS, AI, Web Development*
Aplicación web bancaria adaptativa impulsada por IA, desarrollada en equipo bajo el nombre *"Los Macacos del Norte"*, logrando el **~4° lugar** en el Reto Banorte.
- ♿ **Accesibilidad avanzada**: Implementación de modos de alto contraste, paletas de colores amigables para daltónicos y tipografía ajustable para una experiencia de usuario altamente inclusiva.
- 🚀 **Colaboración Ágil**: Integración exitosa de componentes del sistema y despliegue de un prototipo funcional y listo para producción, presentado y validado durante el evento.
